# M3j implementation plan

Spec: [integer design](../specs/2026-10-20-m3j-integer-design.md).
Inline execution; existing dedicated branch/cache; one whole-branch reviewer.

## Task 1: typed integer IR and parsing

- [x] Add integer.rs parser tests for all32 spellings, mixed-width shifts,
  conversion destination/source widths, wrong operand types/counts, unsupported
  modifiers and uninitialized sources. Confirm RED before implementation.
- [x] Add Convert{to,signed}, And/Or/Xor/Not/Shl/Shr/SignedShr. Explicit cvt
  parsing accepts only four formats; shifts read count as U32. Preserve inferred
  pointer proof. Run cargo test -p ct-ptx and commit.

## Task 2: semantics-preserving code generation

- [x] Codegen tests for width-specific conversion/bitcast and shift comparison,
  bounded-count selects,32-bit shift-count loads and logical final zero-select.
  Confirm RED then implement safe lowering in emit.rs using pinned opcodes.
- [x] Run parser/codegen and workspace tests, formatting, Clippy; commit.

## Task 3: native connection and evidence

- [x] Add a CPU-oracle Python harness with runtime seed operands, literal edge
  patterns, shift boundaries and all conversions. Batch bounded generic PTX
  probes; compare every boolean result and guards through raw/compressed inputs,
  both known profiles. Baseline hash/rejection, invalid syntax recovery and
  independent CUDA C/CLI byte preservation are required. Record actual counts.
- [ ] Run workspace including native/producer, Python, M2/M3h regressions,
  production export26 check and private failure probes. Validate docs/manifest,
  review entire branch, privacy scan, push/attach stacked draft PR, no merge.

## Review focus

Check source/destination signedness, same-width identity/narrowing, signed64
arithmetic shifts, U32 counts for64-bit bases, counts at/above width never passed
to raw SPIR-V shift, predicate result types, conservative pointer proof,
runtime rather than constant-only sources, independent CPU bit arithmetic,
bounded batches, input formats, unchanged ABI and existing fault containment.
No full signed arithmetic,8/16/vector ABI, NVIDIA parity or general P03 completion.
