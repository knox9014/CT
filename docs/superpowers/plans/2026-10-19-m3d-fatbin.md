# M3d Real CUDA Fatbin PTX Loading Plan

> Execute inline with test-first changes and independent review.

**Goal:** Load a genuine NVIDIA-created fatbin through the unchanged official vectorAddDrv host and execute its embedded PTX on Intel Arc.

**Spec:** `docs/CUDA-CONNECTION.md`; user approved continuing from M3c's explicitly deferred actual fatbin step. Keep sources/executable and vendor-produced container bytes unchanged during CT staging/execution. No system DLL/driver modifications.

## Fixed scope and contracts

- Use official nvFatbin12.4.99 to package the original kernel's NVRTC12.0.76 PTX. Explicitly disable compression for the positive test; also generate genuine compressed and multiple-PTX negative containers. This producer is a local ignored test dependency, not used by CT's runtime decoder.
- New dependency-free ct-fatbin crate parses bounded byte slices. Support raw fatbin magic0xba55ed50, outer version1/header16 and record version0x0101 with one uncompressed PTX record. Validate lengths, alignment, metadata/identifier/options bounds, NUL termination/padding, 64-bit CUDA Windows flags and profile limits. Maximum16MiB image,256 records,4096-byte record header and256KiB extracted PTX.
- Skip bounds-checked opaque CUBIN records when a single PTX exists; never execute NVIDIA machine code. No PTX, compressed PTX, multiple PTX modules, nonempty JIT options, unknown format/kinds/flags or unsupported profiles return explicit errors; do not concatenate or guess a module.
- Malformed data maps to INVALID_PTX218; recognized unsupported forms map to NOT_SUPPORTED801. The existing CUDA API has no image-length argument: callers must provide readable PTX C strings or an entire readable binary image matching its declared length. A pure slice decoder supplies truncation/bounds testing; arbitrary invalid C pointers cannot be validated.
- Detect raw fatbin before scanning NUL-terminated text. Inspect first four bytes incrementally so short valid C strings remain safe. Reject runtime wrapper magic without following embedded host pointers. Enforce the cap before forming a binary slice.
- CLI staging checks exact outer file length for binary .fatbin assets; CT performs full record/PTX validation. PTX text under .fatbin remains supported for M3c regression.
- NVIDIA nvFatbin can normalize PTX comments/padding. Preserve and hash the actual resulting container; report extracted text separately from compiler-input bytes. No claim of original nvcc-fatbin parity, compression, linking or full CUDA support.
