# M2 PTX to Intel Execution Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans and test-first changes, then independent review.

**Goal:** Translate a documented PTX subset into SPIR-V and execute vector add, SAXPY, ReLU and simple matrix multiply through CT's CUDA module/launch ABI on Arc B390.

**Architecture:** A dependency-free PTX lexer/parser produces typed register/control-flow IR, validates definitions on every reachable path, and rejects unsupported syntax. A separate SPIR-V code generator lowers instructions, byte addresses, predicates, mutable registers, branches and loops. The native Intel backend loads compiled modules and dispatches synchronously; context-owned opaque module/function handles are exposed by CT.

**Spec:** `docs/CT-DRIVER-DESIGN.md`, M2. This is a restricted experimental subset, not nvcc/cudart/application compatibility.

## Constraints

- One visible entry per module; PTX 7.0, sm_50 baseline, address_size64. Explicit .ptr.global.align4 annotations for f32 pointer parameters, plus u32/f32 scalar parameters.
- 1D grid/block only, no streams, dynamic shared memory, packed argument extra, atomics, shared memory or warp semantics.
- Supported registers: pred, u32/b32, u64/b64, f32. Strict operand typing and definite assignment. No silently ignored directives/modifiers.
- Instructions: parameter/global f32 loads/stores; mov, cvta.to.global, add/sub, mul.lo.u32, mul.wide.u32, mad.lo.u32, div/rem.u32, separate rn f32 add/mul/sub, setp.ge/lt/eq unsigned and lt/ge f32, selp.f32, predicated/unconditional bra, ret.
- No kernel-name/fixture-hash pattern replacement. Renamed kernels, modified immediates, lengths and group sizes must alter or preserve execution according to PTX semantics.
- Trusted kernels only: caller must provide valid memory extents and terminating code. Launch checks ownership and argument starts but cannot prove all dynamic accesses are in bounds.
- Privacy guards remain mandatory. Do not log source text or personal file paths. No source/compiled-module cache is published.

## Tasks

1. Add synthetic PTX fixtures and failing parser/type/control-flow tests. Implement lexer, typed IR and definite-assignment validation, including loops, bounded input size and strict rejection.
2. Add failing codegen tests, implement SPIR-V generation using pinned Khronos opcode definitions. Emit Function-local register storage, explicit control flow, native pointer conversions and NoContraction on f32 arithmetic. Validate with actual driver compilation; official spirv-val remains unavailable unless separately acquired.
3. Add independent C module/launch host and observe failure against M1 DLL. Extend backend module/kernel lifetime management and CT exports: cuModuleLoadData, cuModuleGetFunction, cuModuleUnload, cuLaunchKernel.
4. Test four kernels on real B390, boundary sizes, renamed entry, changed constants, unsupported PTX, stale/foreign handles, argument ownership and rejected launch options. Regress M0/M1, ABI oracle, privacy checks, formatting and clippy.
5. Independent review, fix material findings and rerun checks. Record exact support/limits and create a separate stacked draft PR without merging main.

## Review focus

- PTX parsing must not silently accept malformed types, predication, directives or unknown instruction modifiers.
- Registers must be initialized on every incoming control-flow path; loop analysis must converge soundly.
- Pointer arithmetic is byte-based; kernel argument widths and u32 arithmetic must remain correct.
- No module/kernel can be destroyed while uncertain native work still references it; context teardown also invalidates owned function handles.
- GPU failures poison/retain resources; no CPU fallback or fake success.

## Initial evidence

- Branch: feat/m2-ptx-intel, based on verified M1.
- Official PTX and Driver API references checked; SPIR-V opcodes/builtins checked against pinned local Khronos grammar.
- Prior M0/M1/native/ABI/publication tests passed before this milestone; no PTX translation previously existed.

## Completion evidence

- Tasks 1–4 implemented. Parser/codegen tests failed before implementation; the independent C host failed against the M1 DLL before module exports existed.
- Independent review found incorrect decimal parsing of leading-zero octal literals. Regression failed before the fix; literals and address offsets now use octal and reject `08`. Targeted reviewer verification passed, with no remaining actionable findings.
- Real GPU: four kernels, 53 cases, 606,660 results and 4,992 guards passed; 613,056 C host checks. Renamed/subtraction and modified floating-constant variants passed.
- All 13 Rust tests including native GPU test passed. M1 210 checks, 12-structure C ABI oracle, six privacy tests, formatting and clippy with warnings denied passed.
- Exact support and unverified areas recorded in `docs/compatibility/ptx-profile.md` and `docs/M2-RESULTS.md`. No official SPIR-V validator or NVIDIA comparison was run.
- Publication remains a separate stacked draft PR against M1; main is not merged.
