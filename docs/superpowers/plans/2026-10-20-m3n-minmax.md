# M3n / P03f integer min/max and abs/neg

Bounded extension of the existing generic PTX parser/SPIR-V emitter on Arc.
Accept min/max.s32/u32/s64/u64 and abs/neg.s32/s64 (12 spellings). Min/max
compare at declared width/signedness, selecting original operand bits. Neg
computes zero minus input modulo2^width. Abs selects negation for negative
inputs, with minimum signed integer retaining its high-bit-only representation
in this bounded two's-complement profile. This boundary is tested against a CPU
oracle; NVIDIA parity is not established. No floating, narrow, relu/packed,
carry/saturation, new ABI or immediate syntax is added.
Reference: [PTX integer arithmetic](https://docs.nvidia.com/cuda/archive/12.1.1/parallel-thread-execution/index.html).
